# Codemap

- `tools/z3dmods/cli.py`: the `z3dmods` commands; composes the modules below.
- `tools/z3dmods/config.py`: the one reader of the environment and `env-assets/local.json`.
- `tools/z3dmods/ctr.py`: decrypted CCI/NCCH/exheader/ExeFS/RomFS reading and `.code` LZ decompression.
- `tools/z3dmods/zsi.py`: OoT3D and MM3D room files: header commands, their CMB models, replacing a model and moving what follows. Scene files: the collision's vertices and triangles, read and written.
- `tools/z3dmods/cmb.py`: CMB models, OoT3D's version 6 and MM3D's 10: textures, materials, meshes, vertices; rewriting one shape's geometry.
- `tools/z3dmods/lzs.py`: unpacks MM3D's LzS-wrapped game files.
- `tools/z3dmods/etc1.py`: 3DS ETC1/ETC1A4 texture decoding.
- `tools/z3dmods/pica_texture.py`: PICA texture decoding (RGBA4444, ETC1, ETC1A4) and Azahar's custom-texture hash and file name.
- `tools/z3dmods/cityhash.py`: CityHash64, the hash under Azahar's texture names.
- `tools/z3dmods/texture_pack.py`: finds a game texture's replacement in an Azahar texture pack by its hash.
- `tools/z3dmods/ctxb.py`: CTXB menu texture bundles.
- `tools/z3dmods/gar.py`: GAR v2 archives (MM3D's layout bundles).
- `tools/z3dmods/hud.py`: redoes a base mod's menu-texture edits on the texture pack's high-resolution copies and draws port-assets' pad glyphs over the 3DS button prompts, on the game's own art where no pack covers it (edit tables in `sets/hud/`).
- `tools/z3dmods/stairs.py`: folds stair-textured ramps in a game's rooms into risers and treads, and the scene's collision triangles on them the same way.
- `tools/z3dmods/ips.py`: IPS parse, apply and build.
- `tools/z3dmods/bps.py`: BPS info and apply, with source and target CRC checks.
- `tools/z3dmods/install.py`: installs a `sets/<game>.json` set into Azahar's `load/`, with an install record.
- `tools/z3dmods/azahar_config.py`: global `qt-config.ini` edits.
- `tools/z3dmods/azahar.py`: the headless Azahar session (Gamescope, XTest keys, RPC RAM and frames, config restore).
- `tools/z3dmods/steps.py`: the scripted step language for runs, over either backend.
- `tools/z3dmods/app.py`: the z3d app's build: the pinned Azahar fork's core into a per-revision prefix, then the app against it; its user folders (copies of the player's data, a link to `load/`) and its flags for a set.
- `tools/z3dmods/harness.py`: the app headless as the run backend: frame-exact input, savestates, watchpoints.
- `tools/z3dmods/input_test.py`: `z3dmods inputtest`: the windowed app in a headless Gamescope driven by XTest keys and mouse and a uinput pad; the picker scenario runs the installed shortcut.
- `tools/z3dmods/play.py`: `z3dmods play [game]`: the app in a window on the player's session, with its own saves: the title picker over the library it writes, or one game.
- `tools/z3dmods/shortcut.py`: the per-machine desktop shortcut that runs `z3dmods play`.
- `tools/z3dmods/host_install.py`: `z3dmods shortcut --host`: the app, its sets and saves in another machine's `~/Games/z3d`, with its shortcuts.
- `tools/z3dmods/symbols.py`: reads each game's decomp (function maps, header offsets, globals) and generates a patch's guest constants.
- `tools/z3dmods/games.py`: per-game guest RAM layout the run steps read (play state, save context, cutscene), resolved from the decomp.
- `tools/z3dmods/patch_build.py`: builds our MIT patch (`patch/<game>/`) into IPS records with clang and lld.
- `tools/z3dmods/options.py`: a patch's switches (`patch/<game>/options.toml`): the generated `options.hpp` and the manifest the app's options menu reads.
- `decomp/oot3d/`: submodule, our fork of zeldaret/oot3d (CC0): OoT3D symbols, structs and RE docs.
- `decomp/mm3d/`: submodule, SomeoneIsWorking/mm3d-decomp (MIT, private): MM3D 1.0-layout symbols, structs and RE docs.
- `patch/<game>/symbols.toml`: which decomp functions, globals and offsets a patch uses.
- `patch/common/`: guest memory and call helpers for the patches, and the Start cutscene skip shared by both games.
  - `ctr.hpp`: 3DS kernel calls and service IPC from inside a title.
  - `cstick.hpp`: the New 3DS C-stick, read from `ir:rst`'s shared memory.
- `patch/oot3d/`: our OoT3D patch: guest layout (`game.hpp`), the Start cutscene skip, its script reader (`cutscene_script.hpp`), Quick Text (`quick_text.cpp`), the right-stick free camera (`free_camera.cpp`), the chord item page (`chord_items.cpp`), autosave (`autosave.cpp`), the per-frame hook that runs them (`play_update.cpp`), its switches (`options.toml`), hook sites and link script.
- `patch/mm3d/`: our MM3D patch on Project Restoration's code layout: guest layout (`game.hpp`), the skip's layout, its script reader (`cutscene_script.hpp`), its switches (`options.toml`), hook sites and link script.
- `app/`: `z3d`, a frontend linked to Azahar's core (the fork's installed `AzaharCore` package): a window to play in, or hidden and driven by stdin lines.
  - `app_config`: the typed command line; a game's setup (ROM, layout, textures).
  - `core_settings`: the core's settings and user path from the config, applied first; a game's settings before it loads.
  - `core_log`: the core's log backend for the app's lifetime.
  - `game_library`: the picker's games from the tools' library file, titles and icons from each dump's SMDH.
  - `game_options`: a game's options: the patch's switches from its manifest plus layout and textures, the player's stored choices, the write into the guest block.
  - `screen_overlay`: the overlay layout: the touch screen drawn over the top screen, placed by which touch screen the game has up.
  - `options_menu`: the picker's options screen for one game.
  - `title_picker`: the in-window title picker (SDL renderer, SDL3_ttf outline text), pad and click.
  - `game_window`: the SDL3 window as the core's `EmuWindow`: native Vulkan surface, per-frame event pump, mouse touch, the menu request; the picker's pump.
  - `pad_input`: the core's `z3d` input engine: keyboard (the player's Azahar keys), gamepads and tool commands.
  - `emulator`: game load, frame stepping, guest memory, savestates, screenshots and write watches.
  - `player`: the windowed loop, paced by the core's frame limiter, until close or the menu request.
  - `frame`: a captured frame and its PNG encoding.
  - `repl`: the stdin command language.
  - `icon/z3d.svg`: the app's icon.
- `sets/`: per-game mod set manifests.
